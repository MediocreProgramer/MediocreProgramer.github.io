Neu entworfen: eine Schleife

Redesigned: one loop

Bevor Code entstand, musste das Modell eine Probe bestehen: fünf echte Aufgaben, Ziel 4 von 5. Es schaffte 3 von 5 und zwei halbe, aber 113 Werkzeugaufrufe ohne einen fehlerhaften. Ich ging weiter und machte aus den zwei Schwächen Regeln: Ein Auftrag ist erst fertig, wenn ein Abschlussbericht existiert, und Build-Befehle stehen in Kontextdateien statt im Gedächtnis des Modells.

Before any code was written, the model had to pass a trial: five real tasks, target 4 of 5. It got 3 of 5 plus two half passes, but made 113 tool calls without a single malformed one. I went ahead and turned the two weak spots into rules: a task is only done when a final report exists, and build commands live in context files, not in the model's memory.

Bewusst weggelassen: Router, Personas, Embeddings, Selbstbewertung, Sprachausgabe, Bildgenerierung. Mail, WhatsApp und Gesundheitsdaten zogen in einen eigenen Datendienst.

Left out on purpose: router, personas, embeddings, self-grading, voice, image generation. Mail, WhatsApp and health data moved to a separate data service.

Zeitplaner

Scheduler

Läuft im Server-Prozess. Immer nur ein Lauf gleichzeitig, weil sich alles eine 8-GB-GPU teilt; ein zweiter fälliger Lauf wartet auf die Sperre. Ein Vorbereitungs-Skript sammelt die Daten ohne Modell, das Modell bewertet nur. Ein gescheiterter Lauf schickt einen Push.

Runs inside the server process. Only one run at a time, because everything shares one 8 GB GPU; a second run due at the same time waits for the lock. A prep script collects the data without a model, so the model only judges. A failed run sends one push.

Ein Modellaufruf, der nicht aufhörte

A model call that would not stop

Ein nächtlicher Testlauf hing 6.792 Sekunden in einem einzigen Modellaufruf: rund 120.000 Tokens Nachdenken in einer Schleife, keine Antwort, die GPU blockiert. Die Morgen-Triage startete erst um 06:25. Die Ursache: Prompt, Testdaten und Prüfung widersprachen sich, und das feste Datum der Testdaten, der 7. Oktober, war genau in dieser Nacht „heute“.

A nightly test run hung for 6,792 seconds in a single model call: about 120,000 tokens of reasoning in a loop, no answer, GPU blocked. The morning triage only started at 06:25. The cause: the prompt, the test data and the check contradicted each other, and the test data's fixed date, 7 October, was "today" on exactly that night.

LösungFix Widerspruch aufgelöst, Testdatum relativ gemacht und jeden Aufruf auf 65.536 Ausgabe-Tokens begrenzt. Die Grenze ist Ollamas eigenes num_predict, keine Uhr, damit eine langsame GPU sie nicht auslöst. Der größte gesunde Aufruf unter 505 gemessenen lag bei etwa 37.000 Tokens.Resolved the contradiction, made the test date relative, and capped every call at 65,536 output tokens. The cap is Ollama's own num_predict, not a clock, so a slow GPU cannot trip it. The largest healthy call in 505 measured was about 37,000 tokens.

Ein NAS-Fehler eine Ebene über der Ursache

A NAS error one layer above its cause

Git meldete vom zweiten PC aus „does not appear to be a git repository“ für ein Spieleprojekt-Repo auf dem NAS. Die eigentliche Ursache: Windows behandelt Hostname und IP des NAS als verschiedene Server, und die gespeicherte Anmeldung passte nur zu einem. Git reported "does not appear to be a git repository" for a game project repo on the NAS, from my second PC. Betriebshandbuch

Runbook

Betriebsregeln, jede aus einem Fehler gelernt

Operating rules, each learned from a failure

  1. Vor jedem Modellstart die GPU prüfen.

    Check the GPU before every model load.

    nvidia-smi, tasklist und Ollamas /api/ps. Ollama teilt sich die Karte mit UE5, ComfyUI und Blender; ein blinder Start kann eines davon abstürzen lassen.

    nvidia-smi, tasklist and Ollama's /api/ps. Ollama shares the card with UE5, ComfyUI and Blender; a blind start can crash one of them.

  2. Unbeaufsichtigt heißt: Alles Unbekannte wird abgelehnt.

    Unattended means: anything unknown is denied.

    Jeder geplante Lauf hat seine eigene kurze Erlaubnisliste. Die gemeinsame Datei für unbeaufsichtigte Läufe, data/permissions-unattended.json, bleibt absichtlich leer: {}.

    Each scheduled run has its own short allowlist. The shared file for unattended runs, data/permissions-unattended.json, stays empty on purpose: {}.

  3. Kindprozesse eines Dienstes nie an dessen Konsole hängen.

    Never hang a service's child processes on its console.

    Auch ein Server ohne Fenster hat eine Konsole. Kindprozesse bekommen stdin=DEVNULL und CREATE_NO_WINDOW.

    A server without a window still has a console. Children get stdin=DEVNULL and CREATE_NO_WINDOW.

  4. Wissen, in welcher PowerShell man ist.

    Know which PowerShell you are in.

    nssm braucht eine erhöhte Shell. Verbundene Laufwerke und cmdkey-Anmeldungen leben in der nicht erhöhten, wegen des geteilten UAC-Tokens. Eine Verwechslung schlägt ohne Fehlermeldung fehl.

    nssm needs an elevated shell. Mapped drives and cmdkey credentials live in the non-elevated one, because of the UAC split token. Mixing them up fails silently.

  5. Prüfen, welcher Prozess auf localhost antwortet.

    Check which process answers on localhost.

    Windows löst localhost zuerst zu ::1 auf. Die Ollama-Tray-App bindet ::, der NSSM-Dienst 127.0.0.1, also kann ein einfaches localhost:11434 den falschen Server erreichen.

    Windows resolves localhost to ::1 first. The Ollama tray app binds ::, the NSSM service binds 127.0.0.1, so a bare localhost:11434 can reach the wrong server.

  6. Vor dem Handeln prüfen, worüber eine Zahl gemessen wurde.

    Check what a number was measured over before acting on it.

    Eine Zählung über nur einen Ordner oder ein Test, der über eine leere Liste läuft, sieht genau wie die erhoffte Antwort aus.

    A count scoped to one folder, or a test looping over an empty list, looks exactly like the answer you were hoping for.
